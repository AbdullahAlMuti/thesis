# Architecture Decision Record (ADR) 001: Initial Dependency Stack and Scaffold Architecture

## Status
Approved

## Date
2026-08-01

## Context & Problem Statement
The primary objective of this project is to build an **Agentic Causal Digital Twin for EURUSD** using MetaTrader 5 decision support.
The execution target is strictly `EURUSD`. The system requires:
1. Leakage-safe data processing and symbol metadata resolution from XM MetaTrader 5 terminal.
2. Market-regime detection using Hidden Markov Models (hmmlearn).
3. Dynamic multi-market causal discovery (Tigramite PCMCI+).
4. Graph Neural Network market encoding (PyTorch Geometric GATv2-GRU).
5. Structural causal simulation for counterfactual market stress tests (XGBoost / Structural Causal Models).
6. Single-objective (PPO) and multi-objective (MORL-Baselines / MO-Gymnasium) reinforcement learning agents.
7. Conservative risk management engine enforcing strict demo-account execution safety.

An initial dependency stack and project architecture must be established that ensures OS/Python compatibility, software safety, reproducibility, and mathematical rigor.

## Decision
Adopt a modular Python-native stack centered around PyTorch 2.x, PyTorch Geometric, Tigramite, hmmlearn, Gymnasium, Stable-Baselines3, MO-Gymnasium, MORL-Baselines, XGBoost, MLflow, and MetaTrader5 API, hosted on Windows OS with Python 3.13 / virtual environment.

### Core Stack Components:
1. **Trading Terminal Interface**: `MetaTrader5` (Official PyPI package connecting to local XM MT5 executable at `C:\Program Files\XM Global MT5\terminal64.exe`).
2. **Causal Discovery Engine**: `Tigramite` (PCMCI+ with partial correlation / non-parametric independence tests).
3. **Regime Identification**: `hmmlearn` (Gaussian HMM with online forward-filtering for live validation).
4. **Graph & Temporal Architecture**: `PyTorch Geometric` (`GATv2Conv`) + `PyTorch` (GRU sequence encoder).
5. **Reinforcement Learning**: `Stable-Baselines3` (PPO) and `MORL-Baselines` / `MO-Gymnasium` (PGMORL/CAPQL for multi-objective vector rewards).
6. **Counterfactual Simulator**: `XGBoost` & custom SCM structural equation models.
7. **Experiment Tracking**: `MLflow` (metrics, parameters, graph artifacts, model checkpoints).
8. **User Interface**: `Streamlit` (Interactive decision-support dashboard).

## Alternatives Considered
1. **FinRL Framework as Core Engine**: Rejected as core dependency because FinRL is heavily oriented towards stock portfolios and multi-asset rebalancing, whereas our primary target is strictly `EURUSD` with continuous scalar exposure and explicit leverage/risk guards. FinRL retained as architecture reference only.
2. **PyTorch Geometric Temporal Package**: Considered for dynamic graph processing, but retained as optional. A custom PyTorch Geometric + GRU pipeline provides finer control over edge weights and time-lagged causality graphs generated by Tigramite.
3. **CrewAI / LangGraph Initial Agentic Core**: Postponed. Numerical modeling (HMM, PCMCI+, GNN, RL) must be fully built, tested, and validated before introducing LLM agentic orchestration layers.

## Evidence & Compatibility Findings
- **OS Compatibility**: Windows 11 64-bit platform detected.
- **Python Runtime**: Python 3.13.4 detected.
- **MT5 Installation**: XM MetaTrader 5 terminal executable verified at `C:\Program Files\XM Global MT5\terminal64.exe`.
- **Package Installation**: MT5, PyTorch, PyG, Tigramite, hmmlearn, SB3, MO-Gymnasium, MORL-Baselines, XGBoost, MLflow, and Streamlit are compatible with Python 3.13 under virtual environment isolation.

## Validation Findings
- Unit test suite initialized under `tests/` covering:
  - Demo Account Safety Guard (rejecting non-demo account numbers, live account flags, and unauthorized trade requests).
  - Offline Mock Data Provider (enforcing strict leakage-safe time indexing and roll-forward validation).
  - MT5 Symbol Discovery Logic (resolving broker-specific suffixes like `EURUSD`, `EURUSD.`, `EURUSDm`, `EURUSD#`).

## Advantages
- **Strict EURUSD Target Focus**: Keeps model evaluation clean and avoids multi-asset exposure bloat while using correlated instruments (GBPUSD, USDJPY, XAUUSD, US500, etc.) as context features.
- **Safety First**: Demo-account guards permanently prevent execution on live real-money accounts.
- **Leakage-Safe Architecture**: Clear temporal boundary guarantees features at time $t$ use only completed candles up to $t$.

## Disadvantages & Risks
- **Tigramite GPL-3.0 License**: Code incorporating Tigramite must comply with GPL-3.0 copyleft terms if distributed.
- **MT5 Windows Dependency**: MetaTrader5 Python package requires Windows OS with local MT5 terminal running for live/demo data fetching. Offline provider interface ensures development can continue without MT5 connection.

## Rollback Plan
If Python 3.13 encounters wheel compilation issues for specific C-extensions (e.g. legacy C++ dependencies), fallback to Python 3.11 virtual environment (`python311`). All core logic is written in standard Python 3.10+ compatible syntax.
